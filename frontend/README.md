# AIRecon Frontend

This is the React frontend for the AIRecon platform, built with Vite.

## Running Locally

To run the development server, you will need Node.js and NPM installed on the host machine (Kali VM).

1. Change directory to the frontend folder:
   ```bash
   cd frontend
   ```

2. Install the dependencies:
   ```bash
   npm install
   ```

3. Start the Vite development server:
   ```bash
   npm run dev
   ```

Since the Vite server is configured to bind to `0.0.0.0`, you can access the frontend from any machine on the network by navigating to:
**http://192.168.126.128:5173**
